## Reading guide and caveats

- **Small n.** Every LLM arm has n = 12 to 20 items (H-bio: 75 trials over 15 steps). One item is
  5 to 8 accuracy points. No claim of statistical significance is made; differences of a single
  item are noise.
- **H-a-scale context arm is truncated by design.** The window keeps 200 of 800 facts
  (`dropped_fraction` 0.75, answerable in context 0.05), so a near-zero context score is expected
  and shows the window limit, not a weakness of the model.
- **`oracle_ctx` is an upper bound, not a fair arm.** The harness calls `reason.solve` and hands
  the result to the model; it is never counted as evidence for the product.
- **H-a-ctx is NOT SUPPORTED** as defined: memory matches the full-context baseline in accuracy
  (0.95 vs 0.95 with bio defaults all, 0.95 vs 1.0 with off) but spends more prompt tokens at this
  size (about 1095 vs 469 per question). Memory pays off only once the facts no longer fit
  (H-a-scale).
- **H-c is NOT SUPPORTED** because the model already solves the easy set alone (1.0); the solver
  adds tokens, not accuracy. On the hard set the tool lifts 0.8824 to 1.0.
- **H-bio** passes 75 of 75 trials. The earlier run (41/45) missed `handshake` 1/3, `advise` 2/3
  and `feedback` 2/3: the model answered `handshake` in prose, tried `reason.solve` instead of
  `meta.advise`, and stored feedback with `memory.ingest`. The tool description now names the three
  self-report verbs and failing calls of those shapes get a `did_you_mean_action` redirect. The
  harness also scores a bare triple list the way the server accepts it, and counts a `meta.batch`
  only when one of its steps is the target.
- **H-mcp** was regenerated: the tool list grew with the actions added since 0.1.0 and the
  self-report sentence, so every design costs more bytes; the ranking (batch < sequential <=
  granular) is unchanged.
- The calibration probe could not reach the server during the battery run; it was rerun alone on
  2026-11-26 (same model, thinking on, bio defaults all) and its single result is the one published
  above.
- Advice evidence in the advised arms accrues in run order and, with concurrency, the order is
  nondeterministic (totals are not).
